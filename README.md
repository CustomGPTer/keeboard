# KeeBoard

KeeBoard is a keyboard for Android with no internet permission: UK and US English, glide typing, 3,963 emojis, offline voice typing, clipboard history, split and floating layouts and your own themes. Free, no adverts, no account. A test build.

Website: https://customgpter.github.io/keeboard/

Download: https://github.com/CustomGPTer/keeboard/releases/download/v0.1.0-beta2/KeeBoard.apk
