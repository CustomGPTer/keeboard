Release notes

What changed in each version of KeeBoard. The newest is at the top.

Version 0.1.0 beta 2 21 November 2026Latest

  • Every keyboard panel now stays above the navigation buttons or gesture bar, upright and sideways.
  • The suggestion row folds away when it is empty, so the keyboard sits lower.
  • Installs over beta 1 and keeps your settings.

Version 0.1.0 beta 1 20 November 2026

  • First test build, not published here.
  • QWERTY with UK and US English, completions and spelling suggestions, glide typing, gestures and accents.
  • 3,963 emojis, an offline set of GIFs and stickers, offline English voice typing and an optional clipboard history.
  • One-handed, split and floating layouts, colours, a background picture, themes, text shortcuts and an encrypted backup.

Checking your download

The file for version 0.1.0 beta 2 is called KeeBoard.apk. It is 83 MB (83,282,633 bytes). Its SHA-256 checksum is:

7b02c79bf3a0e53c5589b6e98fe170b8537035eeed8cdbd78e76710380392aa1

On Windows, run certutil -hashfile KeeBoard.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
